ГОЛОСОВИЙ АСИСТЕНТ
==================

Слухає ключове слово («Hey Jarvis», openWakeWord), виконує голосові команди й відповідає через LLM.
Один файл — assistant.py. Розпізнавання мови, голос і ключове слово працюють локально,
у мережу йде текст запиту до LLM (і знімок екрана, коли ти про нього просиш) та, якщо вибрано голос
Edge (Остап, Поліна), текст відповіді для озвучення. Хочеш усе локально — голос Piper або cloud = false.


ЩО ВМІЄ
-------
  • Ключове слово + команда одним реченням, як Siri:  «Hey Jarvis, відкрий steam».
    Лише «Hey Jarvis» — програється сигнал, і асистент чекає команду.
  • Прості команди виконуються миттєво й без інтернету: відкрити програму, пауза/наступний трек,
    гучність, таймер, температура й заряд батареї.
  • Складні питання йдуть у LLM; відповідь озвучується українським голосом (Остап чи Поліна, або локальний Piper).
  • «Що на екрані?», «подивись сюди», «що це за помилка» — знімок активного монітора йде в LLM.
  • Майже все, що скажеш: файли, пошук в інтернеті, вікна Hyprland, яскравість, wifi, bluetooth, будь-які
    команди оболонки. Кілька дій в одній фразі: «відкрий steam і discord, зроби гучність сорок, потім
    постав таймер на п'ять хвилин». Небезпечне виконується лише після твого голосового «так».
    (розділ МАЙЖЕ ВСЕ І КІЛЬКА КОМАНД нижче).
  • Писати й читати: «надрукуй привіт», «прочитай виділене», «запиши нотатку …», «натисни ентер»
    (розділ ПИСАТИ І ЧИТАТИ нижче).
  • Замість озвучення підтверджень («Відкриваю…») грають твої звуки з теки sounds/.
  • Оверлей: прозоре коло з точок, що обертається, реагує на голос (як cava), «думає» швидше при
    навантаженні CPU, а всередині з'являються знаки (✓ ✕ ? ! ↗ ♪ таймер екран).
  • Протоколи — сценарії з кількох дій: «Hey Jarvis, протокол вечірка» вмикає гучність, Spotify, музику.
    Режими — «режим тиша», «режим гра», «режим приватність».
  • Без інтернету: прості команди працюють, для питань можна підключити локальну модель (ollama).


ШВИДКИЙ СТАРТ
-------------
1. Потрібні тільки uv та Wayland/Hyprland. Скрипт сам підтягне Python-пакети.
2. Згенеруй конфіг і поклади ключ API:

     uv run --managed-python assistant.py --init-config
     mkdir -p ~/.config/voice-assistant
     printf '%s' 'ТВІЙ_КЛЮЧ' > ~/.config/voice-assistant/api_key
     chmod 600 ~/.config/voice-assistant/api_key

   У config.toml вкажи api.url та api.model (OpenAI-сумісний API).
3. Перевір, чого не вистачає:

     uv run --managed-python assistant.py --check

4. Перевір ключове слово (скажи «hey jarvis», дивись оцінку моделі; Ctrl+C — вихід):

     uv run --managed-python assistant.py --wake-test

5. Запусти:

     uv run --managed-python assistant.py --daemon

   Перший запуск довгий: докачуються моделі (Vosk ≈ 70 МБ, whisper small, голос Piper ≈ 60 МБ).

Чому --managed-python: на NixOS Python із nixpkgs не бачить бібліотек, які потрібні колесам
(numpy, onnxruntime), а Python, який завантажує сам uv, працює через nix-ld.


NIXOS
-----
У конфігу NixOS:

  programs.nix-ld = {
    enable = true;
    libraries = with pkgs; [
      stdenv.cc.cc.lib zlib
      libGL libxkbcommon wayland fontconfig freetype dbus glib zstd   # для оверлею (Qt)
    ];
  };

Інші пакети: pulseaudio (parec, paplay, pactl — він потрібен і віртуальному мікрофону; сервер має бути
pipewire з services.pipewire.pulse.enable = true), grim (знімок екрана), libnotify (notify-send),
wireplumber (wpctl), brightnessctl (яскравість), networkmanager (nmcli), bluez (bluetoothctl),
glib (gio: кошик), xdg-utils (xdg-open), wtype (введення тексту й клавіш), wl-clipboard (wl-paste, wl-copy: читання
виділеного й буфера). Без grim не працюватимуть питання про екран, без wtype — друк і клавіші,
без wl-clipboard — читання виділеного, без решти — відповідні функції.


HYPRLAND (Lua-конфіг)
---------------------
Автозапуск і гаряча клавіша (SUPER+A — почати слухати без ключового слова, SUPER+S — стоп):

  hl.on("hyprland.start", function()
    hl.exec_cmd("uv run --managed-python <ШЛЯХ>/assistant.py --daemon")
  end)
  hl.bind("SUPER + A", hl.dsp.exec_cmd('kill -USR1 "$(cat "$XDG_RUNTIME_DIR/assistant.pid")"'))
  hl.bind("SUPER + S", hl.dsp.exec_cmd('kill -USR2 "$(cat "$XDG_RUNTIME_DIR/assistant.pid")"'))   -- СТОП: перервати асистента

Вікно оверлею (app_id voice-assistant-overlay) має бути плаваюче, без фокусу, тіней і розмиття:

  hl.window_rule({
    name = "voice-assistant-overlay",
    match = { class = "voice-assistant-overlay" },
    float = true, pin = true, no_focus = true, center = true,
    no_blur = true, no_shadow = true, no_anim = true, border_size = 0,
  })

Оверлей з'являється по центру екрана. У Hyprland 0.56.2 правила move/size для плаваючих вікон
ігноруються (issue #16446), тому позицію не задано. Якщо Hyprland поскаржиться на ключ правила,
прибери його. Переглянути оверлей без решти:  uv run --managed-python assistant.py --ui-demo


НАЛАШТУВАННЯ
------------
Усе налаштовується у config.toml (створюється командою --init-config; шаблон має пояснення до
кожного пункту). Файл шукається в такому порядку, береться перший знайдений:
  1. $ASSISTANT_CONFIG
  2. config.toml поруч із assistant.py
  3. ~/.config/voice-assistant/config.toml
Пріоритет значень:  змінна середовища  >  config.toml  >  типове значення.
Зміни діють після перезапуску асистента.

Найчастіше потрібне:

  [wake]  model = "hey_jarvis"         модель openWakeWord
          threshold = 0.25             поріг впевненості 0..1: менше — чутливіше
          mic_threshold = 0.01         поріг гучності для розпізнавання команди
  [api]   url, key_file, model         LLM; model_fast/tools/smart/vision — окремі моделі за потреби;
                                       model_vision має вміти читати зображення
          fallback_url, fallback_model локальна модель, коли немає інтернету
  [stt]   backend = "whisper"|"vosk"   whisper точніший, vosk швидший і легший
          whisper_model, threads       менше потоків — менше нагрівається ноутбук
  [voice] speaker = "остап"            остап | поліна | диктор | бас | жвава | спокійна (Edge)
                                       лада | микита | тетяна (Piper, офлайн);  enabled = false — повна тиша
          output = "speakers"          speakers | mic | both — куди йде голос (віртуальний мікрофон)
  [ui]    enabled, scale               оверлей
  [apps]  назва = команда              що можна відкрити голосом (steam = "steam")
  [aliases] назва = ["варіанти"]       як ти вимовляєш назву або як whisper її «чує»

Відповідність ключів змінним середовища (на випадок разових змін):
  wake.model ASSISTANT_WAKE_MODEL · wake.threshold ASSISTANT_WAKE_THRESHOLD · behavior.keep_warm ASSISTANT_KEEP_WARM · behavior.prewarm ASSISTANT_PREWARM ·
  behavior.followup ASSISTANT_FOLLOWUP · behavior.barge_in ASSISTANT_BARGE_IN · wake.words ASSISTANT_WAKE · wake.aliases ASSISTANT_WAKE_ALIASES · wake.vosk_model VOSK_MODEL ·
  wake.mic_threshold ASSISTANT_VAD · api.url ASSISTANT_API_URL · api.key ASSISTANT_API_KEY ·
  api.key_file ASSISTANT_API_KEY_FILE · api.model[_fast|_tools|_smart|_vision] ASSISTANT_MODEL[_…] ·
  api.escalate ASSISTANT_ESCALATE · api.fallback_url/_model ASSISTANT_FALLBACK_URL/_MODEL ·
  stt.backend ASSISTANT_STT · stt.whisper_model WHISPER_MODEL · stt.threads WHISPER_THREADS ·
  stt.vosk_model VOSK_STT_MODEL · voice.enabled TTS · voice.speaker PIPER_SPEAKER ·
  voice.speed PIPER_SPEED · voice.model_path PIPER_MODEL · voice.cloud ASSISTANT_TTS_CLOUD ·
  voice.output ASSISTANT_OUTPUT · voice.mic_name ASSISTANT_MIC_NAME · voice.mic_mix ASSISTANT_MIC_MIX ·
  voice.api_url ASSISTANT_TTS_URL · voice.api_model ASSISTANT_TTS_MODEL · ui.enabled ASSISTANT_UI ·
  ui.scale ASSISTANT_UI_SCALE · screen.max_side ASSISTANT_SCREEN_MAX ·
  behavior.local_first ASSISTANT_LOCAL_FIRST · behavior.browser BROWSER_CMD ·
  behavior.sounds_dir ASSISTANT_SOUNDS · behavior.recorder ASSISTANT_REC · behavior.notes ASSISTANT_NOTES · behavior.shell ASSISTANT_SHELL
Приклад разового запуску:  ASSISTANT_STT=vosk uv run --managed-python assistant.py --daemon


КОМАНДИ
-------
  --daemon        основний режим: слухач ключового слова (або SIGUSR1 від гарячої клавіші)
  (без аргументів) один раз послухати і вийти, без ключового слова
  "текст"         текстовий режим:  assistant.py "що ти вмієш"
  --protocol НАЗВА виконати протокол без голосу (з --dry — лише показати кроки)
  --init-config   створити config.toml з поясненнями
  --check         перевірити пакети, програми, API, моделі, звуки
  --wake-test     оцінка openWakeWord у реальному часі й рівень мікрофона
  --ui-demo       показати оверлей у всіх станах
  --forget        очистити історію розмови
  --voices        список голосів     --speak "текст" [--voice лада] [--output mic]   перевірити голос
  --mic-off       прибрати віртуальний мікрофон


ЗВУКИ ЗАМІСТЬ ОЗВУЧЕННЯ
-----------------------
Тека sounds/ поруч зі скриптом (створюється при першому запуску). Назва файлу = подія:

  слухаю.mp3      сказано лише ключове слово (або натиснута клавіша) — говори команду
  відкриваю.mp3   відкрито програму / сайт / файл
  готово.mp3      виконано дію (гучність, таймер, плеєр)
  помилка.mp3     щось не вийшло
  не_зрозумів.mp3 нічого не розпізнано
  офлайн.mp3      немає інтернету, розумію лише прості команди

Формати: mp3, wav, ogg, flac, m4a, opus. Кілька варіантів однієї події (відкриваю_2.mp3,
відкриваю_3.mp3) — щоразу вибирається випадковий. Перезапусти асистента після змін.
Звичайні відповіді LLM озвучує вибраний голос.


МАЙЖЕ ВСЕ І КІЛЬКА КОМАНД
------------------------
Кілька команд в одній фразі розділяй словами «і», «та», «потім», «затим» або паузою-комою:
  «Джарвіс, відкрий steam і discord, зроби гучність сорок, потім постав таймер на п'ять хвилин»
Прості дії асистент виконує сам по черзі й грає один підсумковий звук; усе, що він сам не розуміє
(«…і знайди рецепт борщу»), віддає LLM — решта фрази виконується, нічого не губиться і не повторюється.
Довільний текст («надрукуй …», «запиши нотатку …», «скажи в мікрофон …») не ріжеться: він забирає всю решту фрази.

Що ще вміє LLM-режим (просто кажи, що треба):
  файли         «що в теці Documents», «прочитай файл notes.txt», «створи файл план.txt з текстом …»,
                «знайди файл про борщ», «відкрий теку Downloads», «видали файл …» (у кошик, після «так»)
  інтернет      «знайди в інтернеті, яка погода у Львові», «прочитай першу сторінку» (DuckDuckGo)
  вікна         «перейди на другий стіл», «перенеси вікно на п'ятий», «закрий вікно», «на весь екран»,
                «які вікна відкриті»
  система       яскравість, «вимкни звук», «вимкни мікрофон», wifi, bluetooth, «заблокуй екран», скріншот, сон
  усе інше      оболонка: «запусти firefox у приватному режимі», «скільки вільно на диску», «встанови …» тощо.
Кілька дій із залежністю він ланцюжить сам: відкрити програму, почекати, надрукувати в ній.

Безпека (behavior.shell у config.toml, або ASSISTANT_SHELL):
  ask    типово. Асистент питає голосом «Виконати: …?» перед кожною командою оболонки, крім безпечного
         читання (ls, date, uptime, df, git status …). Відповідай «так»; тиша чи будь-що інше = ні.
  allow  питає лише про небезпечне: rm, sudo, mv, chmod, kill, nixos-rebuild, вимкнення, `| sh`, запис у /etc …
  off    команд оболонки немає взагалі.
Завжди з підтвердженням: перезапис наявного файлу, видалення (лише в кошик), сон. Файли доступні
лише в домашній теці; ~/.ssh, ~/.gnupg, ключі, паролі та ключ API асистенту недоступні.
Усе, що приходить з інтернету, файлів, виводу команд, буфера й екрана, асистент вважає даними, а не
наказами. Режим «приватність» вимикає LLM, а з ним усе це.

ГОЛОСИ І ВІРТУАЛЬНИЙ МІКРОФОН
-----------------------------
Голоси (список: --voices або «які у тебе голоси»; змінити: «Джарвіс, голос поліна» — запам'ятовується):
  остап, поліна      нейронні голоси Microsoft Edge: найприродніші, але потрібен інтернет
  диктор, бас        Остап нижчий і повільніший;   жвава, спокійна — Поліна швидша / повільніша
  лада, микита, тетяна   Piper: локальні, без інтернету (тихіші й «роботизованіші»)
Без інтернету, у режимі «приватність» або з cloud = false хмарний голос сам заміняється на Piper.
Свої голоси — у config.toml: [voices."назва"] engine = "edge", id = "uk-UA-OstapNeural", rate = "-8%",
pitch = "-15Hz". Будь-який інший голос Edge — за повною назвою: speaker = "uk-UA-PolinaNeural".
Для ще більшої кількості голосів: voice.api_url = адреса OpenAI-сумісного /audio/speech (додає alloy,
nova, onyx тощо; хмарні, українську читають із акцентом).

Віртуальний мікрофон — щоб асистент говорив у Discord, дзвінках, OBS замість тебе. Асистент створює
в PipeWire вхід «Assistant Microphone» (voice.mic_name); у програмі вибери його як мікрофон.
  speakers   голос лише в динаміки (типово)       mic    лише у віртуальний мікрофон (тебе в дзвінку чують, ти ні)
  both       і ти чуєш, і чутно в дзвінку         змінити: voice.output, режими «мікрофон» (both) і «ефір» (mic)
  «Джарвіс, скажи в мікрофон <текст>» (або «скажи за мене …») — озвучує фразу лише в дзвінок.
  mic_mix = true домішує твій справжній мікрофон: тоді в дзвінку чути і тебе, і асистента.
Перевірка: uv run --managed-python assistant.py --speak "Привіт" --output mic  (і вибери вхід у програмі).
Вузол живе до перезавантаження звукового сервера, заново створюється при запуску; прибрати: --mic-off.
Якщо в списку входів ти шукаєш власний вузол (наприклад «Microphone [Microphone input]»), звірся:
pactl list short sources — і задай voice.mic_name так, як хочеш його бачити.


ПИСАТИ І ЧИТАТИ
---------------
Працює в активному вікні (оверлей фокус не забирає). Потрібні wtype і wl-clipboard (розділ NIXOS).
Прості фрази виконуються миттєво без LLM; складніші («напиши відповідь на цей лист») — через LLM.

  надрукуй <текст>         вводить сказане дослівно (також: набери, введи, диктуй)
  напиши <що завгодно>     LLM сам складає текст і вводить його у вікно
  прочитай виділене        озвучує виділений текст («прочитай буфер» — скопійований)
  підсумуй виділене        LLM читає виділене й відповідає: стисло, переклад, пояснення
  запиши нотатку <текст>   дописує рядок із часом у ~/Documents/voice-notes.md (behavior.notes)
  прочитай нотатки         озвучує останні 5 нотаток
  натисни ентер, ескейп, таб · скасуй (Ctrl+Z) · збережи (Ctrl+S) · скопіюй · встав · виріж ·
  виділи все · видали виділене
                           клавіші; LLM може й інші комбінації: Ctrl/Shift/Alt + літера чи
                           цифра, стрілки. Ctrl+Alt і Ctrl+Q заборонені.
Довгий текст озвучується до ~1200 символів, вводиться до 2000. Диктування бере whisper (він
точніший за Vosk), тому відповідь трохи запізнюється проти простих команд.


ПРОТОКОЛИ (СЦЕНАРІЇ)
--------------------
Протокол — набір кроків, які виконуються по черзі. Кажи «Hey Jarvis, протокол <назва>» (можна
«запусти протокол …») або фразу-тригер цілою фразою («Hey Jarvis, добраніч»). Вони виконуються
окремим легким процесом: без whisper і без LLM, тож швидко й без інтернету.

Готові (вбудовані):
  вечірка   гучність 65, Spotify, пауза 3 с, музика (play)
  фокус     тиха музика, таймер на 25 хвилин, режим «тиша» (асистент мовчить)   [«працюємо»]
  перерва   режим вимкнено, музика на паузі, таймер на 10 хвилин               [«перерва»]
  кіно      музика на паузі, гучність 45, режим «тиша»                          [«кіно»]
  гра       Steam і Discord, гучність 50, режим «гра» (без голосу й оверлею)    [«граємо»]
  добраніч  музика на паузі, гучність 15, режим «тиша»                          [«добраніч»]
  доповідь  каже час, стан системи (температура, батарея, пам'ять) і що грає   [«доповідь»]

Свої протоколи — у config.toml (кириличну назву пиши в лапках):

  [protocols."ранок"]
  triggers = ["добрий ранок"]
  steps = [
    { mode = "off" },
    { volume = 35 },
    { say = "Доброго ранку!" },
    { time = true },
    { status = true },
    { url = "https://calendar.google.com" },
  ]

Дії кроку (в кожному кроці рівно одна):
  say = "текст"           сказати голосом (Piper)
  sound = "готово"        зіграти звук з теки sounds/
  app = "spotify"         відкрити програму з [apps]
  url = "https://…"       відкрити сайт
  player = "play"         play | pause | next | previous | play_pause | stop | seek_forward | seek_back
  volume = 40             гучність, %
  timer = "25m"           таймер: 90, "90s", "25m", "1h30m"; label = "що нагадати"
  status = true           сказати стан системи         playing = true   що зараз грає
  time = true             сказати час                  notify = "текст" сповіщення
  wait = 3                пауза в секундах (до 60)
  mode = "тиша"           увімкнути режим; mode = "off" — звичайний
  run = "команда"         запустити будь-яку програму (лише з config.toml: модель такого не вигадає)

Помилка кроку не зупиняє решту. Вбудований протокол можна змінити (те саме ім'я) або вимкнути:
[protocols."кіно"] disabled = true. Перевірка без виконання:
  uv run --managed-python assistant.py --protocol вечірка --dry
Список і помилки в кроках показує --check.


РЕЖИМИ
------
Режим змінює поведінку, поки його не вимкнеш, і зберігається між перезапусками. Кажи
«Hey Jarvis, режим тиша», «увімкни режим гри», «вимкни режим» або «звичайний режим».

  тиша         без голосу й звуків (оверлей лишається)
  гра          тиша + без оверлею (не заважає грі)
  приватність  лише локальні команди: до LLM нічого не йде, знімки екрана не робляться,
               whisper не запускається

Свій режим у config.toml:

  [modes."ніч"]
  voice = false          # без озвучення і звуків
  ui = true              # false — без оверлею
  private = false        # true — нічого не надсилати в LLM
  volume = 15            # гучність при вмиканні режиму

Протокол може вмикати режим кроком mode = "…" (так працюють «фокус», «кіно», «гра»).


ШВИДКІСТЬ, СТОП І СОН
---------------------
Швидкість. Раніше кожна складна команда запускала новий процес і заново вантажила whisper. Тепер:
  • Після відповіді процес лишається «теплим» (behavior.keep_warm, типово 60 с): наступна команда
    обробляється без завантаження моделей. Ще 5 с (behavior.followup) асистент слухає БЕЗ ключового
    слова — можна одразу уточнити: «а завтра?». 0 вимикає обидва.
  • behavior.prewarm = "wake" стартує воркер одразу на ключове слово (швидше, але гріє ноутбук
    і для простих команд це зайве); типово "smart" — щойно чути перше слово команди.
  • Пауза в кінці фрази скорочена до 0.7 с (змінна ASSISTANT_END_SILENCE); довгі речення починають
    озвучуватись по комі, не чекаючи крапки.
  • У журналі видно, де йде час: «⏱ моделі готові / розпізнано / відповідь LLM почалась / перший звук».
    Якщо довго «відповідь LLM» — повільний API (змінюй api.model), якщо «розпізнано» — whisper
    (менша stt.whisper_model або stt.backend = "vosk"), якщо «перший звук» — голос Edge/мережа.

Ключове слово. Слухають двоє: openWakeWord («hey jarvis») і Vosk, який чує «Джарвіс …» просто
в тій самій фразі (нечіткий збіг: джарвіс, жарвіс, чарвіс, джервіс, ярвіс, «джар віс», «хей джарвіс»).
Це допомагає, коли англійську модель збиває швидка мова чи акцент. openWakeWord тепер спрацьовує на
один сильний кадр або на два помірних, тому швидке «Jarvis» не губиться. Подивитись, що чує Vosk:
--wake-test; якщо він пише інше слово, додай його в wake.aliases (через кому).

Стоп і відбій.
  • «Джарвіс, відбій» (також: відміна, забудь, не треба, нічого, помилково, це не тобі, не слухай) —
    хибне спрацювання: асистент мовчки закривається, нічого не виконуючи.
  • «Джарвіс, замовкни» (досить, припини) — перервати відповідь. «Стоп»: поки асистент говорить або
    щойно його перебили — зупиняє асистента, в інший час — пауза музики, як раніше.
  • Сказати «Джарвіс» посеред його відповіді — перебити його й дати нову команду (behavior.barge_in).
  • Гаряча клавіша SUPER+S (kill -USR2) зупиняє будь-що негайно.

Сон. Окремого «режиму сну» асистента немає: слухач і так майже нічого не споживає, поки мовчиш.
«Джарвіс, режим сну» (засни, в сон) переводить КОМП'ЮТЕР у сон після твого «так». Асистент переживає
сон: після пробудження сам перезапускає запис, віртуальний мікрофон і воркери. Тиші-режими:
«режим тиша», «режим гра», протокол «добраніч» (музика на паузі, гучність 15, асистент мовчить).


ЯК ЦЕ ПРАЦЮЄ (І ЧОМУ НЕ ЇСТЬ ПАМ'ЯТІ)
-------------------------------------
Постійно працює лише легкий слухач: мікрофон, крихітна ONNX-модель openWakeWord і Vosk, який
вмикається тільки коли є голос. По кроках:
  1. Слухач чує ключове слово й одразу показує оверлей.
  2. Просту команду («відкрий steam», «пауза», «гучність 40», «таймер на 5 хвилин») він виконує сам.
  3. Усе інше він передає окремому процесу: whisper + голос + LLM. Процес стартує, поки ти ще
     договорюєш фразу (звук йому передається без втрат), відповідає й лишається теплим на хвилину;
     далі завершується, і пам'ять повертається. Оверлей закривається сам після відповіді.
Холодний старт whisper (кілька секунд) буває лише на першу складну команду після паузи.


БЕЗ ІНТЕРНЕТУ
-------------
Якщо API недоступний, прості команди працюють як зазвичай. Для питань задай локальну модель:
api.fallback_url = "http://localhost:11434/v1", api.fallback_model = "…" (ollama). Інакше
зіграє офлайн.mp3.


ПРИВАТНІСТЬ
-----------
  • Звук мікрофона не залишає комп'ютер: ключове слово й команди розпізнаються локально.
  • До LLM іде текст запиту та історія розмови (останні 10 повідомлень, зберігаються 10 хвилин
    у ~/.local/state/voice-assistant/history.json; очистити: --forget).
  • Знімок екрана надсилається лише на запит про екран і лише з активного монітора.
  • Вивід команд, вміст файлів і результати пошуку, які асистент прочитав за твоїм проханням, йдуть до LLM.
    Пошукові запити йдуть до DuckDuckGo, сторінки качаються напряму з сайту.
  • Голоси Edge (Остап, Поліна): текст відповіді йде на сервіс озвучення Microsoft. Локально — Piper;
    у режимі «приватність» або з voice.cloud = false хмарний голос не використовується ніколи.


УСУНЕННЯ ПРОБЛЕМ
----------------
  libstdc++.so.6 / інша lib…so не знайдено
      Запускай з --managed-python і додай бібліотеки в programs.nix-ld (розділ NIXOS).
  CERTIFICATE_VERIFY_FAILED під час завантаження моделей
      Скрипт підставляє системні сертифікати сам; якщо не допомогло:
      SSL_CERT_FILE=/etc/ssl/certs/ca-bundle.crt uv run --managed-python assistant.py --daemon
  Рівень мікрофона 0.0000 у --wake-test
      Мікрофон заглушений або вибрано не те джерело: wpctl get-volume @DEFAULT_AUDIO_SOURCE@,
      wpctl status; перевір апаратну клавішу вимкнення мікрофона.
  Ключове слово не спрацьовує
      --wake-test показує і оцінку openWakeWord, і що чує Vosk. Якщо Vosk пише інше слово — додай його
      в wake.aliases; якщо оцінка не доходить до порогу — зменш wake.threshold (напр. 0.2).
      Можна казати й просто «Джарвіс», і «hey jarvis», з командою в тій самій фразі.
  Спрацьовує сам по собі
      Збільш wake.threshold (0.4-0.6) і прибери з wake.aliases слова, на які Vosk реагує даремно.
      Хибне спрацювання гаситься словом «відбій». Музика й розмова поруч теж можуть його давати.
  Погано розпізнає слова (наприклад «зупини музику» → «зупини мозоку»)
      Збільш модель: stt.whisper_model = "medium" (або "large-v3-turbo") — точніше, але повільніший
      холодний старт і більше пам'яті на ці секунди. Типові помилки для плеєра виправляються
      самі, коли у фразі є «зупини/вимкни/увімкни/пауза». Свої помилки додавай у [aliases].
  Голос раптом став «роботизованим»
      Нема інтернету або Edge не відповів: асистент хвилину говорить Piper, потім пробує знову.
  Мікрофон «Assistant Microphone» не з'явився
      Потрібні pactl і pipewire-pulse (розділ NIXOS). Перевір: pactl list short sources.
  Асистент мовчить і не показує оверлей
      Можливо, увімкнено режим «тиша»/«гра»: скажи «вимкни режим» (або видали ~/.local/state/voice-assistant/mode).
  Оверлей не з'являється або з'являється як звичайне вікно
      Перевір --ui-demo, бібліотеки nix-ld і правило Hyprland (розділ HYPRLAND).
  «потрібен grim»
      Додай grim у систему (питання про екран).
  Помилка від API на питанні про екран
      Модель не вміє читати зображення: задай api.model_vision.
  401 від API
      Перевір ключ: --check.
