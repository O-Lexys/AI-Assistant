Поклади сюди аудіо (mp3, wav, ogg, flac). Назва файлу = подія:

  слухаю.mp3 — сказав лише ключове слово (або натиснув клавішу) — говори команду
  відкриваю.mp3 — відкрито програму / сайт / файл
  готово.mp3 — виконано дію (гучність, таймер, плеєр)
  помилка.mp3 — щось не вийшло
  не_зрозумів.mp3 — нічого не розпізнано
  офлайн.mp3 — немає інтернету, розумію лише прості команди

Кілька варіантів однієї події: відкриваю.mp3, відкриваю_2.mp3, відкриваю_3.mp3 — щоразу вибирається випадковий.
Перезапусти асистента після змін.
