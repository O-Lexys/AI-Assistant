Шпаргалка: голосовий асистент

Ключове слово: «Оріон» (або «Hey Orion»). Команду можна казати в тій самій фразі: «Оріон, відкрий steam». Лише ключове слово — пролунає «слухаю», далі говори команду.

1. Запуск і CLI

Усі команди: uv run --managed-python assistant.py …

Команда Що робить
--daemon основний режим: слухає ключове слово
(без аргументів) один раз послухати й вийти, без ключового слова
"текст" текстовий режим: assistant.py "що ти вмієш"
--init-config створити config.toml з поясненнями
--check перевірити пакети, програми, API, моделі, звуки
--wake-test оцінка openWakeWord, що чує Vosk, рівень мікрофона
--vision-test які моделі справді бачать зображення
--ui-demo показати оверлей у всіх станах
--protocol НАЗВА [--dry] виконати протокол без голосу (--dry — лише показати кроки)
--voices список голосів
--speak "текст" [--voice лада] [--output mic] перевірити голос і вивід
--forget очистити історію розмови
--mic-off прибрати віртуальний мікрофон

Разова зміна налаштування: ASSISTANT_STT=vosk uv run --managed-python assistant.py --daemon

2. Керування розмовою

Дія Як
Почати слухати без ключового слова гаряча клавіша (kill -USR1, у прикладі — SUPER+A)
Зупинити все негайно (і відео, і трек) гаряча клавіша (kill -USR2, SUPER+S)
Хибне спрацювання «Оріон, відбій» (відміна, забудь, не треба, нічого, помилково, це не тобі, не слухай)
Перервати відповідь «Оріон, замовкни» (досить, припини, годі, вистачить)
Перебити посеред відповіді скажи «Оріон» і нову команду
Уточнити після відповіді ще ~5 с слухає без ключового слова: «а завтра?»
Слово «стоп» поки асистент говорить — зупиняє його, в інший час — пауза музики

3. Миттєві команди (без LLM, без інтернету)

Що Приклади
Програми «відкрий steam», «запусти discord»
Плеєр «пауза», «продовжуй», «наступний трек», «попередній»
Гучність «гучність сорок», «гучніше», «тихіше»
Таймер «таймер на 5 хвилин», «нагадай через 10 хвилин»
Що грає «що зараз грає»
Система «стан системи», «температура процесора», «скільки заряду»
Клавіші «натисни ентер / ескейп / таб», «скасуй», «збережи», «скопіюй», «встав», «виріж», «виділи все», «видали виділене»
Сон комп'ютера «режим сну» (після твого «так»)

Кілька команд в одній фразі — розділяй «і», «та», «потім», «затим» або комою: «Оріон, відкрий steam і discord, зроби гучність сорок, потім постав таймер на п'ять хвилин». Те, чого він не розуміє, віддається LLM; решта все одно виконується.

4. Писати й читати

Фраза Результат
«надрукуй привіт» (набери, введи, диктуй) вводить сказане дослівно в активне вікно
«напиши відповідь на цей лист» LLM складає текст і вводить його
«прочитай виділене» / «прочитай буфер» озвучує виділений / скопійований текст
«підсумуй виділене» LLM: стисло, переклад, пояснення
«запиши нотатку …» дописує рядок із часом у ~/Documents/voice-notes.md
«прочитай нотатки» озвучує останні 5
«скажи в мікрофон …» / «скажи за мене …» озвучує фразу лише у віртуальний мікрофон (дзвінок)

5. Питання про екран

«що на екрані?», «подивись сюди», «що це за помилка», «що в мене відкрито», «прочитай це». Назви програму чи гру («що в грі», «що в дискорді») — знімається саме її вікно; без назви — усі монітори (до 3). Потрібен grim.

6. Талісман на екрані

Вигляд: [ui] look = "bot" (робот) або "orb" (чорна діра).

Що Команди
Рух «перейди в правий нижній кут», «стань справа / зліва / по центру», «підійди до курсора», «іди за вікном», «гуляй», «залишайся тут»
Видимість «сховайся» (з'являється лише на розмову), «з'явись»
Картки (миттєво) «що ти вмієш показувати», «покажи скріншот», «покажи стан системи», «покажи вікна», «покажи нотатки», «прибери картку»
Ефект «зроби бах»
Через LLM (потрібен інтернет) «знайди в інтернеті … і покажи», «покажи qr для https://…», «покажи картинку ~/Pictures/файл.png», «покажи, як виглядає сайт …», «покажи таблицю …»

Режими руху: follow (біля активного вікна, типово), wander (блукає), stay (стоїть). Режим і позиція запам'ятовуються.

7. Відео, треки, меми

Що Команди
Трек «постав трек Океан Ельзі Обійми», «увімкни пісню Imagine Dragons Believer»
Відео «пусти кліп Despacito», «покажи відео про котів», посилання або файл із домашньої теки
Керування «пауза», «продовжуй», «стоп» (годі, досить, вистачить, замовкни, прибери відео)
Меми «покажи мем», «ще мем»
Свій мем «зроби мем про те, що код працює, а я не знаю чому»

Коли кажеш «Оріон», музика ставиться на паузу й сама продовжується після відповіді. «Увімкни музику» без назви керує Spotify/браузером (MPRIS). Для YouTube потрібен deno або nodejs у PATH.

8. Що ще вміє LLM-режим

Область Приклади
Файли «що в теці Documents», «прочитай файл notes.txt», «створи файл план.txt з текстом …», «знайди файл про борщ», «видали файл …» (у кошик, після «так»)
Інтернет «знайди в інтернеті, яка погода у Львові», «прочитай першу сторінку»
Вікна «перейди на другий стіл», «перенеси вікно на п'ятий», «закрий вікно», «на весь екран», «які вікна відкриті»
Система яскравість, «вимкни звук», «вимкни мікрофон», wifi, bluetooth, «заблокуй екран», скріншот
Інше будь-яка команда оболонки: «скільки вільно на диску», «запусти firefox у приватному режимі»

9. Режими

Кажи «режим <назва>», «увімкни режим гри», «вимкни режим» або «звичайний режим». Зберігається між перезапусками.

Режим Що змінює
тиша без голосу й звуків, оверлей лишається
гра тиша + без оверлею й талісмана
приватність лише локальні команди: до LLM нічого не йде, знімків екрана немає
мікрофон голос чутно і тобі, і у віртуальному мікрофоні
ефір голос лише у віртуальному мікрофоні

Свій режим: [modes."ніч"] з voice, ui, private, volume.

10. Протоколи

Кажи «протокол <назва>» або фразу-тригер цілою фразою. Працюють без whisper і LLM, тому швидко й офлайн.

Протокол Тригер Що робить
вечірка — гучність 65, Spotify, пауза 3 с, музика
фокус «працюємо» гучність 20, таймер 25 хв, режим «тиша»
перерва «перерва» режим вимкнено, музика на паузі, таймер 10 хв
кіно «кіно» пауза, гучність 45, режим «тиша»
гра «граємо» Steam і Discord, гучність 50, режим «гра»
добраніч «добраніч» пауза, гучність 15, режим «тиша»
доповідь «доповідь» час, стан системи, що грає

Кроки власного протоколу (рівно одна дія в кроці): say, sound, app, url, player, volume, timer ("25m", "1h30m"), status, playing, time, notify, wait, mode, run. Перегляд без виконання: --protocol вечірка --dry.

11. Голоси й віртуальний мікрофон

Що Як
Список «які у тебе голоси» або --voices
Змінити «Оріон, голос поліна» (запам'ятовується)
Edge (потрібен інтернет) остап, поліна, диктор, бас, жвава, спокійна
Piper (локально) лада, микита, тетяна
Вивід voice.output: speakers / mic / both
Вхід у Discord, OBS у програмі вибери «Assistant Microphone»

12. Безпека команд оболонки (behavior.shell)

Значення Поведінка
ask (типово) питає «Виконати: …?» перед кожною командою, крім безпечного читання; відповідай «так»
allow питає лише про небезпечне: rm, sudo, mv, chmod, kill, вимкнення, запис у /etc
off команд оболонки немає

Завжди з підтвердженням: перезапис файлу, видалення, сон. Файли доступні лише в домашній теці.

13. Налаштування, які потрібні найчастіше

Порядок пошуку config.toml: $ASSISTANT_CONFIG → поруч зі скриптом → ~/.config/voice-assistant/config.toml. Пріоритет: змінна середовища > config.toml > типове. Зміни діють після перезапуску.

Ключ Навіщо
wake.threshold 0..1: менше — чутливіше (типово 0.25)
wake.aliases варіанти слова, які чує Vosk («джервіс», «чарвіс»)
wake.mic_threshold поріг гучності мікрофона
stt.backend, stt.whisper_model, stt.threads точність проти швидкості й нагріву
api.url, api.model, api.model_vision LLM і модель із зором
api.fallback_url, api.fallback_model локальна модель без інтернету (ollama)
voice.speaker, voice.output, voice.cloud голос, куди звук, офлайн-голос
ui.look, ui.idle, ui.move, ui.scale, ui.bubble талісман
behavior.keep_warm, followup, prewarm, barge_in швидкість відповіді
[apps], [aliases] що відкривати голосом і як ти вимовляєш назви

14. Якщо щось не так

Проблема Що робити
Не спрацьовує ключове слово --wake-test; додай слово в wake.aliases або зменш wake.threshold (0.2)
Спрацьовує сам збільш wake.threshold (0.4–0.6); «відбій» гасить хибне спрацювання
Погано розпізнає слова stt.whisper_model = "medium" або "large-v3-turbo"
Довго відповідає дивись журнал ⏱: «розпізнано» — whisper, «відповідь LLM» — API, «перший звук» — голос/мережа
Мовчить і без оверлею можливо, режим «тиша» / «гра»: «вимкни режим»
«Не бачить» екран --vision-test, потім api.model_vision
YouTube: «Requested format is not available» додай deno або nodejs у PATH
Рівень мікрофона 0.0000 wpctl get-volume @DEFAULT_AUDIO_SOURCE@, wpctl status
401 від API перевір ключ: --check
Оверлей не з'являється --ui-demo, бібліотеки nix-ld, правило Hyprland

15. Де що лежить

Шлях Що
sounds/ поруч зі скриптом свої звуки замість озвучення (слухаю, відкриваю, готово, помилка, не_зрозумів, офлайн)
~/.config/voice-assistant/api_key ключ API
~/.local/state/voice-assistant/ історія, режим, голос, стан талісмана, кеш медіа
~/Documents/voice-notes.md нотатки
$XDG_RUNTIME_DIR/assistant.pid PID для гарячих клавіш
